# Crop Recommendation System
India's GDP is mostly dependent on agriculture and farmers. But due to unavailability of the adequate tools and technologies many time farmers are not able to grow the crops that will give highest yield.
So, in this project we have build a crop recommendation system to make the crop selection easy for the farmers and help them in gaining highest amount of profit.

In this application Farmers will enter Atmosphoric conditions and soil composition and based on it the crop to grow.
